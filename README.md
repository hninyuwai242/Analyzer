
N-Gram Name Destiny Analyzer

N-Gram Name Destiny Analyzer is a beautiful desktop application developed in Python using Tkinter. It combines Natural Language Processing (NLP) techniques, customized transliteration algorithms, and numerology frameworks to predict destiny and offer career, lifestyle, and relationship insights based on English or Myanmar names and birth dates.

🔮 Features


1. Language Detection & Transliteration

• Dual-Language Processing: Automatically detects whether the input name is written in English or Myanmar script.
• Myanmar-to-English Transliteration: Maps Myanmar characters natively to their English phonetic counterparts using a comprehensive syllable and character dictionary.

2. Destiny & Analytical Engine

• N-Gram Future Predictions: Utilizes deterministic ID hashing based on character traits (vowel count, word length, character weights) to provide categorized insights:
	• 🎓 Education (ပညာရေး)
	• 💼 Career & Employment (အလုပ်အကိုင်)
	• 💰 Wealth & Finance (ငွေကြေး)
	• ❤️ Family & Relationships (မိသားစု)
	• 🏥 Health & Wellness (ကျန်းမာရေး)
	• 🌏 International Relations (နိုင်ငံခြားရေးရာ)
	• 🤝 Social Connections (လူမှုဆက်ဆံရေး)
	• 🧭 Life Guidance (ဘဝလမ်းညွှန်)

3. Intelligent Name Suggestion System

• Smart Recommendations: Uses the Levenshtein Distance algorithm to calculate typographical distances between names and automatically suggest the top 5 closest matching names from a dataset.
• Bonus Weights: Factors in matching initial characters, ending characters, and text length ratios to refine recommended outputs.

4. Numerology Metrics (ဂဏန်းဗေဒ)

• Computes core numerological values for both English names and Myanmar characters.
• Maps numbers (1 through 9) to comprehensive profiles highlighting Strengths, Weaknesses, Ideal Career Paths, and Core Destiny.
